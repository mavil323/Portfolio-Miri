# Developer Portfolio Website

## Overview

This repository contains the source code for my personal developer portfolio website built using React. The site presents my technical projects, skills, and experience in a structured and accessible format for recruiters, collaborators, and potential employers.

It serves as a central hub linking to my GitHub work while demonstrating modern front-end development practices and component-based architecture.

---

## Features

* Responsive layout across devices
* Component-based UI architecture
* Project showcase with descriptions and links
* Skills and technology summary
* Contact section for professional outreach
* Clean and accessible interface design

---
